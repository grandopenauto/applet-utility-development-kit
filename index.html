API-first by design

Applets are reusable across dashboards, scripts, and client applications. This GitHub Pages demonstration executes only in your browser. Use the local Node server for the REST API.

GET /api/appletsList versioned applets
POST /api/validateValidate macro configuration
POST /api/runExecute a declarative macro
POST /api/codeGenerate JavaScript source
POST /api/testRun built-in self-checks

The public demo does not expose live HTTP API endpoints. Run npm start locally for /api/* routes. No arbitrary operating-system commands or remote code execution are enabled.
