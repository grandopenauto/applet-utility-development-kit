Applet Review & Promotion Desk New · v0.7
Generate evidence, verify packet integrity, and prepare a human-reviewed promotion proposal. No automatic library or GitHub publishing.

          
Review boundary: A local reviewer label is NOT authenticated approval. SHA-256 detects alterations but does not prove authorship. Proposed applets still require manual source inspection, GitHub pull-request review, and passing CI before merge.

02 · Local human reviewNot an authorization credential

                
                
                
                
              

              
03 · Controlled publicationNo automatic merge

                
Export the proposal, run local validation, submit the proposed library entry through a GitHub pull request, and merge only after human review and CI. A packet is not a published applet.

                npm run review:propose -- --packet candidate.review.json --reviewer "Reviewer Name" --note "I inspected both outputs" --acknowledge

API-first by design
Applets are reusable across dashboards, scripts, and client applications. This GitHub Pages demonstration executes only in your browser. Use the local Node server for the REST API.
POST /api/factory/previewGenerate and validate an applet manifest without publishing it
GET /api/blueprintsRead available schema-driven functions
POST /api/blueprints/previewGenerate, test, and preview an applet blueprint
GET /api/universal/functionsList reviewed Python callable recipes and parameter schemas
POST /api/universal/previewValidate and preview a review-ready applet candidate
GET /api/library/search?category=MathematicsSearch verified registry metadata on the local API
GET /api/appletsList versioned applets
POST /api/validateValidate macro configuration
POST /api/runExecute a declarative macro
POST /api/codeGenerate JavaScript source
POST /api/testRun built-in self-checks
The public demo does not expose live HTTP API endpoints. Run npm start locally for /api/* routes. No arbitrary operating-system commands or remote code execution are enabled.
